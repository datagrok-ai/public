# Old components

Legacy UI kept so that Compute (v1) and apps built on compute-api keep working: the old history panel,
list and input, the old run save and delete dialogs, their grid and favorites helpers, the run queries
they list runs with (`pullRuns`, `pullRunsByName`) and their column constants.

Compute2 doesn't use anything from this folder. Its behavior doesn't change, and it takes critical fixes only.
