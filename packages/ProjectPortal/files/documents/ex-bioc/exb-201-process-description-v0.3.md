# Process description, Antibody Alpha (EXB-201), draft 0.3

Example document on synthetic data. Nothing here describes a real process.

- Production: fed-batch, 14 days, 36.5 °C, feed 3% v/v per day from day 3.

- Capture: Protein A, low-pH elution.

Open: the feed strategy rests on the selected Fed-batch titer run.
