```datagrok-exec
const fg = view.getFiltersGroup({createDefaultFilters: false});
const filters = fg.filters;
for (const f of filters) {
  if (f.filterType === DG.FILTER_TYPE.SUBSTRUCTURE) {
    f.detach();
  }
}
```

This removes only the substructure filter from the active filter group, leaving all other filters (range, categorical, free-text, etc.) intact.
