I'll find the molecule column in your table and apply a benzene substructure filter.

```datagrok-exec
// Find the molecule column (semType = 'Molecule' or look for SMILES-like columns)
let molCol = null;
for (const col of t.columns) {
  if (col.semType === 'Molecule' || col.semType === 'molecule') {
    molCol = col;
    break;
  }
}
// Fallback: look for columns named smiles, molecule, structure, etc.
if (!molCol) {
  const names = ['smiles', 'molecule', 'structure', 'mol', 'canonical_smiles', 'smi'];
  for (const name of names) {
    const c = t.col(name);
    if (c) { molCol = c; break; }
  }
}
if (!molCol) throw new Error('No molecule column found. Please set the semantic type of your molecule column to "Molecule".');

// benzene SMILES → molBlock → substructure filter
const benzeneSmiles = 'c1ccccc1';
const molBlock = DG.chem.convert(benzeneSmiles, DG.chem.Notation.Smiles, DG.chem.Notation.MolBlock);

view.getFiltersGroup({ createDefaultFilters: false }).updateOrAdd({
  type: DG.FILTER_TYPE.SUBSTRUCTURE,
  column: molCol.name,
  columnName: molCol.name,
  molBlock,
  molBlockFailover: benzeneSmiles,
});
```

This applies a **benzene ring substructure filter** (`c1ccccc1`) to your molecule column using the filter panel. Only rows containing a benzene ring will remain visible. The filter widget will appear in the **Filters** panel on the right where you can adjust or remove it.
