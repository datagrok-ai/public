```datagrok-exec
// Find and remove only the substructure filter from the active filter group
const fg = view.getFiltersGroup({ createDefaultFilters: false });
const filters = fg.filters;
let removed = 0;
for (const f of filters) {
  if (f.filterType === DG.FILTER_TYPE.SUBSTRUCTURE) {
    fg.remove(f);
    removed++;
  }
}
if (removed === 0) {
  return ui.divText('No substructure filter found.');
}
```

This removes the substructure filter from the filter panel while leaving all other active filters (range, categorical, free-text, etc.) untouched.
