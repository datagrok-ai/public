```datagrok-exec
const calcCols = t.columns.toList().filter(c => c.meta.formula != null);
const names = calcCols.map(c => c.name);
for (const n of names) t.columns.remove(n);
return ui.divText(names.length > 0
  ? `Removed calculated columns: ${names.join(', ')}`
  : 'No calculated columns found.');
```

This removes every column that has a formula attached (i.e. all calculated columns), regardless of when they were added. The result will tell you which columns were removed.
