```datagrok-exec
const calcCols = t.columns.toList().filter(c => c.meta.formula != null).map(c => c.name);
for (const n of calcCols) t.columns.remove(n);
return ui.divText(calcCols.length > 0
  ? `Removed ${calcCols.length} calculated column(s): ${calcCols.join(', ')}`
  : 'No calculated columns found.');
```This scans every column for a non-null `meta.formula` (the marker of a calculated column) and removes them all. The result message will tell you how many were removed and their names.
