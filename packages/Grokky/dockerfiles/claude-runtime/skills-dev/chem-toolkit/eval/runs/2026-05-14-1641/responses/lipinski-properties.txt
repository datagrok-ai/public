Done! The following Lipinski properties have been computed and appended as new columns to your table:

| Column | Description |
|--------|-------------|
| **MW** | Molecular Weight |
| **HBA** | Hydrogen Bond Acceptors |
| **HBD** | Hydrogen Bond Donors |
| **LogP** | Lipophilicity (octanol-water partition coefficient) |

These are the four core **Lipinski Rule of Five** descriptors. A drug-like molecule typically satisfies: MW ≤ 500, HBA ≤ 10, HBD ≤ 5, and LogP ≤ 5.
