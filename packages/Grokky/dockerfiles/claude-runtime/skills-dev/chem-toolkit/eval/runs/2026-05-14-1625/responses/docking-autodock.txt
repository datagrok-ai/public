Based on the chem-toolkit skill, I'll call `Docking:getAutodockResults` to dock the ligand into the `1aki` target with 5 poses.

```datagrok-exec
const ligandSmiles = 'CC(=O)Nc1ccc(O)cc1';

// Create a small dataframe with the ligand
const df = DG.DataFrame.fromColumns([
  DG.Column.fromStrings('smiles', [ligandSmiles])
]);
df.columns.byIndex(0).semType = DG.SEMTYPE.MOLECULE;

grok.shell.addTableView(df);

const result = await grok.functions.call('Docking:runAutodock', {
  table: df,
  ligands: df.col('smiles'),
  target: '1aki',
  poses: 5
});
```

This will:
1. Create a table with your ligand **CC(=O)Nc1ccc(O)cc1** (Acetaminophen / Paracetamol)
2. Run **AutoDock Vina** against the **1aki** target with **5 poses**
3. Display the docking results with binding energies, sorted by score, with color coding applied to the grid

The results will include binding energy scores (kcal/mol) for each pose — lower (more negative) values indicate stronger predicted binding. You'll also be able to visualize the 3D poses in the NGL viewer by clicking on a result row.
