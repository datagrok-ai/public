
```datagrok-exec
const mol = t.columns.bySemType(DG.SEMTYPE.MOLECULE);
if (!mol) throw new Error('No molecule column found in the current table.');
await grok.functions.call('Admetica:getAdmeProperties', { table: t, molecules: mol });
```

ADME properties have been calculated and appended as new columns to your table. The predictions cover:

- **Absorption** — Caco-2 permeability, solubility, bioavailability, etc.
- **Distribution** — BBB penetration, plasma protein binding, VD, etc.
- **Metabolism** — CYP inhibition/substrate profiles
- **Excretion** — half-life, clearance

Scroll right in the grid to see all the new ADMET columns. You can also click on any molecule cell to open the **Biology | Admetica** context panel for a per-compound summary.
