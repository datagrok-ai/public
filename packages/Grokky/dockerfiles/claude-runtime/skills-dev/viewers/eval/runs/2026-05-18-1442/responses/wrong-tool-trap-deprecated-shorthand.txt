I need to point out that `view.scatterPlot()` is **deprecated** in the Datagrok JS API. The correct way to add a scatter plot is via `view.addViewer(DG.VIEWER.SCATTER_PLOT, ...)`.

```datagrok-exec
view.addViewer(DG.VIEWER.SCATTER_PLOT);
```

This adds a scatter plot to the current view using the recommended, non-deprecated API. If you'd like to specify columns (e.g., x, y, color), just let me know the column names and I'll configure it accordingly.
