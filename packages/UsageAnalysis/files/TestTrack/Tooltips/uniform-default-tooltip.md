### Viewers: uniform default tooltip

1. Open a scatter plot and a box plot
2. Open grid properties, set `Show Tooltip` to `inherit from table` (the grid's own default is a custom tooltip
   with no columns, which shows nothing) and enable `Show Visible Columns In Tooltip`
3. Hover over the viewers (including the main grid): the tooltip should consist of the same set of columns in the same order
