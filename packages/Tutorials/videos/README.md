# Datagrok how-to videos

142 short how-to videos in 16 playlists, 137:57 in all: one idea each, filmed from a Gherkin
scenario of the Tutorials bdd project (`bdd/features/howto/<section>/`, tag `@guide @tutorial`) with `grok-bdd guide`,
so every video is also a test of what it shows.

The videos are not in the repository: they are in `~/Desktop/grok/Core/howto-videos/<section>/<NN - Title>.mp4` on the
machine that filmed them. Each section's `descriptions.md` holds its playlist name and, per video, the YouTube title and
description; `REVIEW.md` the reviewer's notes. To film a clip again: `npx grok-bdd guide features/howto/<section>/<file>`
in `packages/Tutorials/bdd` (one feature per run, so nothing one clip leaves on the page shows in the next).
