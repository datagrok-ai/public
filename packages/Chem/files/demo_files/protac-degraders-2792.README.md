# protac-degraders-2792.csv

2,792 PROTAC degraders, each split into warhead, linker and E3 ligand, for the SAR Matrix's PROTAC demo
(`Cheminformatics | PROTAC SAR Matrix`, project `sar_matrix_protac_demo.zip`). The predicted solubility is
`Solubility logS (pred)`.

Source: PROTAC-PatentDB, Scientific Data 12, 1840 (2025), https://doi.org/10.1038/s41597-025-06136-9 (data:
https://doi.org/10.6084/m9.figshare.29351321), licensed under CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/). Changed from the source: the molecules are split into the
three parts and filtered (only rows whose parts rejoin into the original molecule), as `misc/protac-dataset/`
in the Chem package describes and builds.
