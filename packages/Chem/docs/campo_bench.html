caMPO weighting — verification bench

Runs the computation from the specification (Cholesky inversion, element-wise weights, clipping, priorities, pins) on preset correlation matrices or on generated data, with the same viewers and validation rules.

R is used as is. Click a cell in the correlation plot to edit it.
Rows are drawn from a multivariate normal with the preset R and mapped to [0, 1] with Φ. R is then recomputed (Pearson, complete rows only), as the viewer would.

Properties

Computation

Intermediate values of both stages. si — row sum of R⁻¹, S — sum of all elements, raw = si/S, base — after clipping, final — after priorities and pins. R²i = 1 − 1/R⁻¹ii.

R⁻¹

Test cases from section 9 of the specification, run against the same functions the bench uses.
